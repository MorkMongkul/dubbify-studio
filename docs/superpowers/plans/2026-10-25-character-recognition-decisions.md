Kept from the build's ledger (2026-10-25/26), which is deleted once the branch is finished. The spec (`docs/superpowers/specs/2026-10-25-character-recognition-design.md`) is the authority; these are the calls made while building it where the spec and plan were silent, wrong or contradicted by measurement, each with what it costs if wrong. Owner-facing questions still open are at the end.

- Ruling I (T3): YuNet must run at the video's own resolution, as the spike did (cv2 setInputSize((w, h)); faces ≥ 40 px are judged at native size — letterboxing a 720×1280 frame to 640 halves them). YuNet's head decoding + NMS, SFace's similarity-transform alignment (port of OpenCV face_recognize.cpp alignCrop → warpAffine INTER_LINEAR 112×112, RGB, no scaling), and the Light-ASD crop (pad 110-grey border, cv2-style bilinear resize to 224, BGR→grey, centre 112) are numpy ports checked against fixtures made with OpenCV 5.0.0 in the spike venv — why: matches what was measured; no OpenCV in the app (Ruling H) — cost if wrong: if the graph can't take symbolic dims, T3 reports BLOCKED and the fallback is per-size sessions or a letterbox with a re-measure.
- Ruling J (T3): follow the spike's details where the plan is silent — each SFace feature L2-normalised before the mean, then the mean normalised; a track continues to the highest-IoU track seen ≤ 0.09 s ago (IoU ≥ 0.3), a new track when that track already has a face at this time; lip audio for a track = audio16[t_first : t_last + 0.04]. With vocals_path None: no voice print and no lip judgement (face None) — T6 skips recognition without vocals anyway — cost if wrong: none.
- Ruling K (T4): "no face match" needs a face floor, else a new actor's speaking face is always handed to the nearest known face. Face pick = best face-profile cosine ≥ UNKNOWN_FACE_FLOOR; no speaking face, or no character with a face profile, or below the floor → no face pick → voice rules. "Nobody" = no face pick and best voice cosine < UNKNOWN_VOICE_FLOOR (or no voice print) — cost if wrong: a few lines go to "new character" instead of a guess; T14's measurement shows it.
- Ruling L (T4): guesses where the spec is silent — no voice print but a face pick → face's top two (basis "face"), to check; nobody → the voice's top two (basis "voice", possibly empty) so the chips still offer them; only ONE character with a voice profile → no margin exists → never sure by margin (sure only when face agrees) — why: never "sure" on thin evidence (Review Focus 3) — cost if wrong: a few more checks in a project's second episode.
